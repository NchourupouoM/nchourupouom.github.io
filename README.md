# Nchourupouo Mohamed — AI/ML Engineer, Data Scientist & Python Developer

Portfolio officiel déployé sur **[https://nchourupouom.github.io](https://nchourupouom.github.io)**.

## Architecture & Design System

- **Design System** : *Soft Obsidian* inspiré de LangChain & LangGraph Studio (`#030710`, surfaces `#0F172A/60`, accents `#7FC8FF` & `#2DD4BF`, grille de points radiale).
- **Simulation Studio Showcase** : Encapsulation des projets IA, Deep Learning et Power BI (`.gif` & `.png`) dans des fenêtres type LangSmith/macOS avec modale plein écran interactive (*Mode Studio*).
- **Stack Frontend** : React 18, Vite, Tailwind CSS, Framer Motion, Lucide Icons.
- **CI/CD** : Déploiement automatisé sur GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`).

## Développement Local
